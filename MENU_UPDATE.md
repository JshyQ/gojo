# Menu Update

- Fixed `.allmenu` crash caused by the missing menu knowledge-base function.
- `.allmenu` now uses nested subcategories for Admin, RPG, Tools, Media, Fun, Bot, Downloader, Music, Panel, Sewa, Premium, etc.
- Added important real command aliases such as `.opengroup`, `.closegroup`, and join-request aliases to menu navigation.
- Admin menu now groups approval, member management, protection, locks, audit/reporting, monitoring, backup/restore, events, schedules, notes, and group settings.
- Registry feature packs are no longer dumped as one flat block; they are grouped by function and duplicate curated commands are filtered.
- `.allmenu` is rendered as compact plain text so it does not split because of an oversized image caption.
