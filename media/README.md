# Folder Media

Letakkan file video di sini untuk fitur `!ryoiken` (Ryoiki Tenkai Kick).

## File yang dibutuhkan

| Nama file              | Dipakai untuk                          |
|-------------------------|-----------------------------------------|
| `ryoiki-tenkai.mp4`    | Video yang dikirim sebelum kick member  |

## Cara isi

1. Siapkan video kamu sendiri (klip Gojo Satoru mengucapkan "Ryoiki Tenkai" atau
   apapun yang kamu mau) dalam format `.mp4`.
2. Beri nama file persis: `ryoiki-tenkai.mp4`
3. Upload / copy ke folder ini (`media/ryoiki-tenkai.mp4`).
4. Restart bot (atau cukup tunggu, karena file dibaca ulang setiap command dipanggil).

Kalau file belum ada, bot otomatis fallback kirim teks "Ryoiki Tenkai" ala
domain expansion supaya command tidak error — begitu file di atas sudah ada,
otomatis dipakai tanpa perlu ubah kode apapun.

> Catatan hak cipta: pastikan kamu punya hak untuk menggunakan video tersebut
> (rekaman sendiri, lisensi, atau footage non-copyright). Project ini tidak
> menyediakan video resmi dari anime/studio manapun.
